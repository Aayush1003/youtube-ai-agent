DAY 1 DSA · TWO POINTERS

Two Sum on Sorted Arrays — Avoid Quadratic O(n²)

Learn how to eliminate nested loops by leveraging sorted invariants with left and right inward pointers.

Ready Short Voiceover (40s)

"Need to solve Two Sum in an interview without checking every pair? If your array is sorted, place pointer L at index zero and R at the end. Sum too small? Increment L. Sum too big? Decrement R. In linear O(n) time with zero extra space, you've solved it!"

Optimal Implementation 
// Java Optimal O(n) Time, O(1) Space
public int[] twoSumSorted(int[] numbers, int target) {
    int left = 0, right = numbers.length - 1;
    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target) return new int[]{left + 1, right + 1};
        else if (sum < target) left++;
        else right--;
    }
    return new int[]{-1, -1};
}
DAY 2 DSA · SLIDING WINDOW

Sliding Window Maximum — The Monotonic Deque

Maintain only useful candidates in strictly decreasing order so each window's maximum is retrieved in O(1) amortized time.

Ready Short Voiceover (45s)

"LeetCode 239 is notoriously tricky until you use a Monotonic Deque. As the window slides right, pop elements smaller than the incoming number from the back, and evict stale indices from the front. The head of the deque is always your maximum!"

Optimal Implementation 
# Python 3: Monotonic Deque O(n)
from collections import deque
def maxSlidingWindow(nums, k):
    q, res = deque(), []
    for i, n in enumerate(nums):
        while q and nums[q[-1]] < n:
            q.pop()
        q.append(i)
        if q[0] == i - k:
            q.popleft()
        if i >= k - 1:
            res.append(nums[q[0]])
    return res
DAY 3 DSA · LINKED LISTS

Floyd's Cycle Finding — Fast & Slow Pointers

Detect loops in linked data structures without allocating a HashSet, preserving constant O(1) memory.

Ready Short Voiceover (35s)

"Imagine two runners on a circular track: one runs twice as fast. Will they collide? Absolutely! The tortoise moves 1 step, the hare moves 2. If slow equals fast, you have a cycle. If fast hits null, there's an exit. Clean, elegant, zero extra space."

Optimal Implementation 
// Java Cycle Detection
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}
DAY 4 DSA · BINARY SEARCH

Binary Search on the Answer Space (Koko Eating Bananas)

Transform optimization problems into monotonic boolean feasibility tests across a known numeric range.

Ready Short Voiceover (45s)

"Binary Search isn't just for sorted arrays. When you see 'find the minimum speed or capacity to finish in H hours', binary search the speed itself! If speed S works, can we go slower? If not, speed up. Turn an O(N) linear sweep into blazing O(log K)!"

Optimal Implementation 
# Python Binary Search on Answer
def minEatingSpeed(piles, h):
    l, r = 1, max(piles)
    res = r
    while l <= r:
        k = (l + r) // 2
        hours = sum((p + k - 1) // k for p in piles)
        if hours <= h:
            res = k
            r = k - 1
        else:
            l = k + 1
    return res

Design a Scalable URL Shortener (TinyURL)

Architecture breakdown: Base62 encoding, distributed ID generation (Snowflake), and Redis caching strategy for high-read throughput.

Ready Short Voiceover (45s)

"How does TinyURL pack billions of links into 7 characters? 62 alphanumeric characters to the power of 7 gives 3.5 trillion unique URLs! Pair a distributed counter with Base62 encoding and a Redis read-through cache, and you have a 100k RPS system."

Base62 Python Snippet 
CHARS = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ"
def encode_base62(num: int) -> str:
    if num == 0: return CHARS[0]
    res = []
    while num > 0:
        res.append(CHARS[num % 62])
        num //= 62
    return "".join(reversed(res))
DAY 6 AI / LLM INTERNALS

How Self-Attention Works: Visualizing Query, Key & Value

Break down the core mathematical intuition powering modern LLMs without unnecessary academic jargon.

Ready Short Voiceover (45s)

"Think of Attention like YouTube search: your Query is what you typed. The Keys are video titles in the database. The dot product compares your Query with all Keys to find relevant matches, and Softmax turns them into weights applied to the actual Value content."

Scaled Dot-Product Formula 
# PyTorch: Scaled Dot-Product Attention
import torch
import torch.nn.functional as F

def attention(Q, K, V):
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / (d_k ** 0.5)
    weights = F.softmax(scores, dim=-1)
    return torch.matmul(weights, V), weights
